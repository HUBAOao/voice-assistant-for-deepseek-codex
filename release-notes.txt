这一版攒了 1 个小改动（电脑端 v1.153）

- v1.153  修了两个「别人那边会出问题」的（顺手查出来的）：① 网站上的 update.zip 根本没生成 —— 更新清单里写着 `update_url: update.zip`，可生成网站的时候只放了 app.apk / pc.zip，所以别人点「检查更新 → 一键更新」下载到的是一个 404；现在更新包跟着一起放上去了。② 老 Release 里还挂着带你令牌的旧安装包 —— 早期那几版手机 APP 的「出厂地址」写死过开发机的地址 + 令牌，而那些 app.apk 一直躺在 GitHub 的 Releases 里（仓库里攒了 12 个 Release），等于把旧口令一直挂在公网上；现在发布流程加了一步：每发一版就把老 Release 全删掉、只留最新那一个
