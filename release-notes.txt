这一版攒了 3 个小改动（电脑端 v1.275）

- v1.276  鳍舱第四十九轮命令闸门与外网设置：停止词、重发、静音、自听回声、听写和状态查询按原顺序收进独立命令闸门，普通聊天继续走原发送管线；外网状态、安装、登录、公网开关和地址复制从悬浮窗外壳拆成设置动作模块，旧方法名、按钮和脱敏展示保持。Android 新增 CSV 与 JSON 单张/多张系统分享，只作为受限附件进入待发送区，文件管理器打开文本的行为保持不变。
- v1.277  鳍舱第五十轮唤醒闸门与外网状态边界：唤醒词、取消词、连续对话、喊错字处理和声纹拒绝按原顺序收进独立唤醒装配，主流程只消费允许状态与正文；设置外网访问进一步拆成状态读取/轮询与实际开关动作两个模块，旧方法名、按钮、异步线程和脱敏展示保持。Android 新增 RTF、EPUB 与 Markdown 单张/多张系统分享及 content/file 打开，仍只进入待发送附件区。
- v1.278  鳍舱第五十一轮手机适配与设备设置边界：手机命令静默上下文、当前会话、切换会话、回答忙碌和公网更新地址适配收进可注入模块；设备许可、连接记录和外网二维码从悬浮窗外壳迁入独立设置业务，旧按钮、方法和脱敏展示保持。Android 通知栏新增“打开鳍舱”和“收下提醒”原生动作，收下只清除完成提醒，不停止后台服务。
