怎么用（三步）

  1. 电脑端：下载 → 解压 → 双击 1-安装语音助手.cmd，装好桌面上会有图标
  2. 手机端：下载 APK 装上，打开 APP 后点左上角「扫码」
  3. 电脑上点悬浮窗的「二维码」按钮，用手机照一下就连上了 （手机和电脑要连同一个 Wi-Fi）

电脑端最近的更新（v1.161）

  • v1.161同一台手机在名单里现在合成一条了（你接着问的「为什么不合并」）：按「IPv6 的 /64 网段 + 时间上对得上的 IPv4」把属于同一台手机的几条记录归成一堆，卡片上写「N 个入口」，点一下「允许 / 拒绝 / 移除」是整台一起处理。确认弹窗也变成一台只问一次（不再为同一台手机弹两三遍）。
  • v1.160设备名单上的名字说人话了（你问的「为什么有三个设备」）：同一台手机其实会占好几条 —— APP 里的页面（WebView）、APP 的后台轮询、传文件各是一个客户端，手机换网之后来源地址也会变，所以一台手机常常是 2~3 条。以前列表上只有一串 UA，看着像有三台陌生设备；现在每条都翻译成「语音助手 APP·页面 / ·后台 / ·接口」「安卓浏览器」「电脑浏览器」这种名字，下面才写原始 UA；名单顶上和弹窗里也直接写明白了「同一台手机可能占好几条，都点允许就行」。
  • v1.159「回答完了」改成实话了 + 手机上能看原话（你说的两件事）：① 以前手机上那条「（某某）回答完了」其实是语音念完这一条，不是电脑那边活干完了，容易误会。现在写的是「（某某）这段语音念完了」—— 电脑那边有没有忙完，看手机上那个状态小圆点/状态文字。② 新增「看原话」（手机「＋」里）：念出来的那份是清理过的（去掉 Markdown、代码块、链接），你想核对原话就看这里 —— 电脑每念一条就把原文另存一份，手机上按时间倒序列出来，长得什么样就显示什么样。只加了个记录，念的内容一个字没改（不影响语音）。
  • v1.158手机上「看电脑屏幕」那张图现在能放大了，也能退出来了（你反馈的 bug）：以前点大图走的是`window.open` —— 在 APP 的网页壳里会开一个关不掉的空窗口，而且根本没缩放。现在换成页面内自己的看图器：捏合放大 / 双击放大（再双击还原）/ 单指拖动看别处，右上角一个 ✕、点图片外的空白也能退，手机返回键也先退图（不会一下退到后台）。电脑上开这页时还能用滚轮缩。
  • v1.157手机端整容 + 加了日程（你点名的四件事）：① 设置分好类了 —— 通用 / 连接 / 关于 / 电脑与通知 / 外观，各带一条分隔线和标题，不再是密密麻麻一长条；② 日程模块上手机了 —— 「＋」里的「日程」进去就是电脑那份日程表：几点、什么内容、每天还是每周，能直接加 / 改 / 删 / 停用（写回电脑的 config.json，电脑上那个日程面板会跟着变）；③ 「＋」弹出来时聊天区被顶上去（跟微信一样，不是盖在上面）；④ 图标统一成一套灰色线描（屏幕/文件/对话/日程/搜索/图片/外观/连接/截图/录/状态/停/头像），不再用表情包 —— 标题栏那个齿轮也换成同一个风格。
  • v1.156多了两个能看能管的地方（你要的）：① 设备名单 —— 设置 → 智能 → 外网访问 → 「名单」，一台一台列出来：谁已允许、谁在等你确认（带 6 位号码）、来源地址、最后一次是几点；每一台都能当场「允许 / 拒绝 / 移除」。② 连接记录 —— 同一行的「连接记录」，按时间倒着列「谁、什么时候、干了什么」：连上来、发命令（还能看到发的是什么）、看屏幕、取文件、传文件、以及在门口发生的事（新设备想连、你允许/拒绝了、有人令牌连错被关门）。记录存在程序目录下的 `phone-access.jsonl`，最多留最近 800 条，能「打开文件」看原始内容、也能一键清空。

手机端最近的更新（v1.28）

  • v1.28手机在电脑名单里现在真的只有一条了（你问的「为什么有三个设备」）：以前 APP 里的几个客户端各算一台 —— 页面（WebView）、后台轮询、发语音用的是不同的 HTTP 客户端，谁也不认识谁。现在它们共用一个设备号：服务端第一次发一个 `va_dev`，APP 存下来，Java 这边的请求都带上它，网页那边的 cookie 也塞同一份。以后同一台手机不管开几个入口、在家还是在外面换网，电脑上都只算一条记录。
  • v1.27「正在连电脑」再也不会一直转下去了（你反馈的：卡了两分钟）：上一版是「先探路、探完再加载」，白白多等 3 秒；更要命的是——要是猜的那条地址根本不通，安卓的 TCP 超时能拖到两分钟，那一页就一直转。现在改成：① 打开立刻用「上次真的打开成功的那条地址」开始加载，不空等；② 后台同时探几条路（局域网 / 上次用的 / 记住的公网地址），只有「刚才猜的那条其实不通」才切过去，顺便把最快的那条记下来，下次直接走它；③ 12 秒还没进页面就自动换成「连不上」那一页（上面有重试 / 扫码连接 / 改地址），那一页上也多了个「一直连不上？点这里」的按钮 —— 再不会让你对着一圈转的动画干等。服务端还顺手开了 gzip：那一页 76KB 压到 22KB，手机少下一大半
  • v1.26打开不再黑屏了（你反馈的）：以前 APP 一开只有一块深色空屏 —— 因为那一下什么都没画，而且它会直接去加载「上次那条地址」，那条路要是不通（比如人在外面、地址却是家里局域网那条），就得等系统自己超时，几十秒才轮换。现在两步一起改：① 打开立刻画一页本地的「正在连电脑…」（带转圈，不联网所以是瞬间的）；② 同时在后台并行探几条路 （局域网那条 / 上次用的 / 记住的公网地址），给每条 1.8 秒，谁先通用谁 —— 在家自动走局域网、在外面自动走公网地址，再也不用先白等一次超时。顺便：「重试」也重新挑路，不在一棵树上吊着；网页资源的缓存也放开了（以前每次打开连图标都重下一遍）
  • v1.25手机上不用再管 Tailscale 了（你问的）：安卓规定 VPN 必须是独立应用，所以 Tailscale 那个 APK 还得装一个（这一条改不了）—— 但现在你只需要开语音助手这一个 APP：① 「外网访问」里多了个 「🔁 后台自动连（设一次）」，点一下带你到安卓的 VPN 设置，把 Tailscale 设成「始终开启的 VPN」，以后它自己连着、界面再也不用打开；② 地址切换也自动化了 —— 打开时局域网（在家）要是连不上，APP 会自己改走记住的那条外网地址；③ 连不上那页现在说准原因：没装 Tailscale / 装了但没连上 / 已经连着那就是电脑那边的事，而不是笼统地怀疑「你是不是开着 VPN」
