安卓 7.0 以上 · v1.233 · 14.6 MB

装完打开 APP，扫电脑上那个二维码就连上了（不用手敲地址）。 手机上打开的这一页，点上面的按钮就能直接下。
📶 想在外面（不在同一个 Wi-Fi）也能用？不用另外找软件 —— 电脑端 设置 → 智能 → 外网访问 点一下「一键开启」（它会自己把 Tailscale 装好、把登录页开出来给你登）；手机 APP 里 设置 → 外网访问 点「装 / 开 Tailscale」， 它会自己把 APK 下下来装上，回来点「用这条地址连」就切过去了。只在家里用就不用管这一栏。
（不想让 APP 自动装的话，也可以直接下 官方的 Tailscale apk）

怎么用（三步）

  1. 电脑端：下载 → 解压 → 双击 1-安装语音助手.cmd，装好桌面上会有图标
  2. 手机端：下载 APK 装上，打开 APP 后点左上角「扫码」
  3. 电脑上点悬浮窗的「二维码」按钮，用手机照一下就连上了 （手机和电脑要连同一个 Wi-Fi）

电脑端最近的更新（v1.316）

  • v1.316鳍舱电脑端 v1.316 单目录便携与插件舱：程序、模型、语音克隆、数据、缓存和日志可固定在同一个 FinDeck 目录；新增 DSH 与 Codex 插件适配，安装后可自动启动完整语音、视觉、桌宠和手机桥接。大肥鱼声线参考音频和默认音色随新版安装包保留，不上传聊天记录、手机文件或账号令牌。
  • v1.315鳍舱电脑端 v1.315 识别模型按需加载：启动时不再把 Whisper 常驻显存；按住说话时先立即录音，同时由一个可重试的单例后台任务加载模型，松开后等待就绪再转写。录音、加载、转写或手机语音请求期间不触发卸载，最后一次使用结束后连续空闲 10 秒才释放模型与 CUDA 缓存；快速连续使用会复用同一模型。
  • v1.314鳍舱电脑端 v1.314 鱼的记忆书册：桌宠右键新增“鱼的记忆”，打开独立的书本界面，含封面、目录、章节页、上一页、下一页和返回目录；正文按共享记忆 Markdown 标题分章，并用 INDEX.md 补全用途与外部章节。每次打开重新读取 E 盘首选路径，缺失时依次回退 F 盘和 C 盘副本，全程只读。
  • v1.313鳍舱电脑端 v1.313 语音输入与 TTS 分离：悬浮窗左下角喇叭成为独立可点击的朗读开关，默认关闭；中间开关仍只控制听音暂停。按住说话待机时也持续轮询该开关；TTS 关闭时进程闸门会立即锁住并终止朗读子进程，开机问候、回答朗读和试听都不再启动 TTS，重新点开后才允许朗读。
  • v1.312鳍舱电脑端 v1.312 壁纸关闭恢复与降耗：关闭桌面动态壁纸时重新应用 Windows 已保存的原壁纸，避免 WorkerW 留下灰底；动态壁纸关闭后常驻桌宠限制为 30 帧，拖动窗口时不再持续占用高帧率透明合成。
  • v1.311鳍舱电脑端 v1.311 壁纸方格与鱼群缩放：按 Windows 当前 32px 系统鼠标指针取一半，将背景单元改为约 11 CSS px 的等宽等高方格；鲨鱼、小鱼、游速与转向节奏同步按网格比例缩小，修正引擎参数未传入绘制器的问题，并保留独立可点击的昼夜控制窗。

手机端最近的更新（v1.233）

  • v1.233鳍舱手机 v1.233 聊天背景可调模糊：像素鲨鱼主题下拉开聊天界面时，整张动态海洋背景会实时高斯模糊，并新增“聊天背景模糊”滑杆，可独立调节 0–36px 强度；关闭聊天界面后恢复清晰背景。

  • v1.231鳍舱手机 v1.231 昼夜像素波纹：白天与黑夜切换从右上角日月按钮位置发射一圈像素格波纹，波纹扫过的区域从旧配色逐格变成新配色，直到覆盖整个屏幕；保留旋转按钮反馈与低动态模式。
  • v1.230鳍舱手机 v1.230 鲨鱼思考光：思考开始时随机选一条鲨鱼，保留原轮廓和字符纹理，把原来的明暗直接映射为暗蓝到亮蓝阶梯；光色使用思考条同款 #4aa3ff，只加很轻的描边光，不再给普通小鱼铺大光晕。浅色模式取消灰度滤镜，改用保留色相的反相，蓝色仍然可见。
