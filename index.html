📶 想在外面（不在同一个 Wi-Fi）也能用？不用另外找软件 —— 电脑端 设置 → 智能 → 外网访问 点一下「一键开启」（它会自己把 Tailscale 装好、把登录页开出来给你登）；手机 APP 里 设置 → 外网访问 点「装 / 开 Tailscale」， 它会自己把 APK 下下来装上，回来点「用这条地址连」就切过去了。只在家里用就不用管这一栏。
（不想让 APP 自动装的话，也可以直接下 官方的 Tailscale apk）

怎么用（三步）

  1. 电脑端：下载 → 解压 → 双击 1-安装语音助手.cmd，装好桌面上会有图标
  2. 手机端：下载 APK 装上，打开 APP 后点左上角「扫码」
  3. 电脑上点悬浮窗的「二维码」按钮，用手机照一下就连上了 （手机和电脑要连同一个 Wi-Fi）

电脑端最近的更新（v1.177）

  • v1.177手机悬浮桌宠又加了三样：①「饭碗」按钮把电脑上的大肥鱼饭碗（余额 / 今日 / 近 7 天 / 最近一步）显示在手机上；②「宠」和「区」分开调——宠是鱼的大小（新增超小号），区是它活动的透明区域大小；③鱼身保持点击穿透，手柄那一小条才接管触摸。
  • v1.176手机悬浮桌宠修好了：之前只有「拖 · 点鱼玩」的把手、下面空白，是安卓 WebView 对 file:// 模块和跨域资源的限制；现在改成 appassets 本地安全源，鱼能正常显示。悬浮窗顶部还加了「大小」按钮，可切小 / 中 / 大。
  • v1.175手机入口的「＋」里多了「桌宠」：打开就是大肥鱼 Live2D，能自己走、能拖能摸；电脑在朗读时它会停住做说话动作。形象资源随安装包带（只带 web，不带 377MB 的 Electron 本体），手机连上电脑就能用。
  • v1.174修了朗读被「¥ / ≈」这类符号打断的问题：送进克隆声线前会转成「元 / 大约」，不会再因为一个符号整段退回旧音色或没声音。
  • v1.173声音输出可选设备：设置 → 声音 → 输出设备，能切系统默认 / 耳机 / 显示器扬声器；耳机没戴或没连时不会再「听不见」。桌宠在朗读时会停住并做说话动作。
  • v1.172悬浮窗展开收起换了实现：主浮窗不再改尺寸，设置面板改成独立窗口淡入淡出，不再每帧重排/重画；顺手修了「两个悬浮窗」和桌宠拖不动（拖出角色后卡在 drag）。

手机端最近的更新（v1.32）

  • v1.32手机悬浮桌宠加了「饭碗」和尺寸分开调：手柄上「饭碗」显示电脑的余额 / 今日 / 近 7 天 / 最近一步；「宠」调鱼大小（含超小号），「区」调活动透明区域；鱼身仍然点击穿透，不挡微信。
  • v1.31修了悬浮桌宠只剩一个把手、下面空白的问题：安卓 WebView 对 file:// 的模块脚本和本地资源有跨域限制，现在改成 appassets 本地安全源，鱼能正常显示；保留顶部拖动条和「大小」按钮。
  • v1.30大肥鱼桌宠能做到手机上、而且浮在所有 APP 上面了：手机入口顶部常驻「桌宠」按钮，点一下变成一个悬浮在所有应用之上的小窗——桌面、微信、浏览器里都在。顶部小条拖动位置，右边「大小」可以切小/中/大；下面的鱼能摸、能自己动；电脑在朗读时它也会做说话动作。第一次点会先让你允许「显示在其他应用上层」。
  • v1.29手机页不再吃缓存了（你反馈的「你改的东西我手机上看不到」）：以前为了省流量，网页壳允许缓存，结果我这边改完手机还在用旧的页面 —— 面板、忙完了提示、气泡那几处你当然看不到。现在改成每次打开都重新取页面（图标这类也一起重取，慢一点点，但保证你看到的永远是最新的）。装完这一版，前面那几次改动才会真的出现在手机上。
