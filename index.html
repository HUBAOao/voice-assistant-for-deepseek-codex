（不想让 APP 自动装的话，也可以直接下 官方的 Tailscale apk）

怎么用（三步）

  1. 电脑端：下载 → 解压 → 双击 1-安装语音助手.cmd，装好桌面上会有图标
  2. 手机端：下载 APK 装上，打开 APP 后点左上角「扫码」
  3. 电脑上点悬浮窗的「二维码」按钮，用手机照一下就连上了 （手机和电脑要连同一个 Wi-Fi）

  • v1.147把 Tailscale 直接做进语音助手里（你要的）—— 以前得你自己去官网下载、自己登录、自己改地址，现在电脑端 设置 → 智能 → 外网访问 里点一下「一键开启」就完事：没装它自己装（先试 winget，不行就下官方 msi 静默装，装的时候会弹一次「是」），没登录它自己跑 `tailscale up` 并把登录网页开在浏览器里，登完地址就固定了（100 开头那一条，重启也不变，另外还会给一条固定域名当备用）。那一栏里还有「复制地址」「二维码」「刷新」：手机在外面（用流量、别的 Wi-Fi）扫一下就切过去，地址固定不用再改。连不上时也不再只丢一句「不可用」，而是直接告诉你卡在哪一步、点哪个按钮
  • v1.146手机在外面也能连（你要的）：电脑上装了 Tailscale（免费、地址固定），Tailscale 会给这台电脑一个固定地址（100 开头那种，重启也不变），桌面上放了张「固定地址二维码」，手机装上 Tailscale、登录同一个账号，扫那张码就把地址换过去了 —— 之后在家、在外面、用流量都能连，而且只有你自己登录的设备能连（别人连端口都看不见，比临时隧道安全）。另外下载站上也加了 Tailscale 的安卓 APK 入口（官方 APK 100.6MB，超过 GitHub 仓库单文件100MB 的上限，所以是让 Actions 挂成 Release 附件，页面链过去）

手机端最近的更新（v1.24）

  • v1.24出厂地址不再带开发机的地址和令牌：以前 APP 默认填的是开发机的局域网 IP + 它自己的口令 —— 等于把口令跟着 APK 发给每个人，同一张网里的人拿到它就能指挥那台电脑。现在默认是一个明显占位的地址，第一次打开会看到一页中文说明：点「扫码连接」照电脑上的二维码，或者点「改电脑地址」手填，就接上了。已经用过的人不受影响（存过的地址还在），只有点「恢复出厂地址」才会变成这个占位值
  • v1.23手机这边也把 Tailscale 做进 APP 了（你要的）：设置里新加「外网访问」那一栏 —— 点「装 / 开 Tailscale」APP 会自己把官方 APK 下下来装上（不用去应用商店找），装好直接点开登录，回来点「用这条地址连」就把电脑地址切成外网固定那条。连不上那一页（比如开着 VPN 白屏）也多了「用外网地址连」和「装 / 开 Tailscale」两个按钮，不用自己琢磨。顺手修了个真 bug：外网那一栏的「复制」按钮以前被误塞进了改名输入框的事件里，所以点了没反应 —— 现在独立出来了
  • v1.22修了个很实际的坑：开着 VPN 时 APP 打不开。不是 APP 坏了 —— 安卓会把去局域网（192.168.x.x）的流量也塞进 VPN 隧道，于是手机找不到你那台电脑，页面加载失败就是一片白。现在：①连不上时不再白屏，而是给一页中文说明，直接告诉你「多半是 VPN」，并给四个按钮（重试 / 打开 VPN 设置 / 改电脑地址 / 扫码连接）；②那个「打开 VPN 设置」会跳到系统的 VPN 页，在里面把语音助手加进「不使用 VPN 的应用」（应用分流）就行 —— 这是最稳的办法：VPN 照常用，只有语音助手走局域网。要提醒一句：这个新版得先装上才生效，你可以用手机浏览器打开下载站（GitHub 那个，开着 VPN 也能开）拿新版，或者临时关掉 VPN 更新
  • v1.21把「一键更新」修好了，并在设置里加了一个常驻入口（你要的）：设置 →「更新」那一行，点「检查更新」就跟电脑上的手机端版本比一下，有新版按钮就变成「一键更新」—— 点一下 APP 自己把新版下载到本机、再拉起系统的安装界面，跟着点「更新」就完事，不用去浏览器、不用自己找文件。以前用不了是三个原因凑一块：①网页把相对地址丢给安卓，Uri.parse 根本打不开（所以点了没反应/说「打不开下载页」）；②就算地址对了，那也只是把浏览器叫起来，浏览器下载完并不会自动装；③安卓 8 以后装 APK 要先允许「安装未知应用」。现在三条都改了：地址补成完整的、APP 自己下载、没权限就先带你去开那个开关（开完回来自动继续下）。技术上是给 APP 塞了一个几十行的迷你 FileProvider（这个 APP 一直不带任何第三方依赖，所以不能用 androidx 那个）
