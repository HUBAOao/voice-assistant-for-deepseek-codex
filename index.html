怎么用（三步）

  1. 电脑端：下载 → 解压 → 双击 1-安装语音助手.cmd，装好桌面上会有图标
  2. 手机端：下载 APK 装上，打开 APP 后点左上角「扫码」
  3. 电脑上点悬浮窗的「二维码」按钮，用手机照一下就连上了 （手机和电脑要连同一个 Wi-Fi）

电脑端最近的更新（v1.158）

  • v1.158同一台手机在名单里现在合成一条了（你接着问的「为什么不合并」）：按「IPv6 的 /64 网段 + 时间上对得上的 IPv4」把属于同一台手机的几条记录归成一堆，卡片上写「N 个入口」，点一下「允许 / 拒绝 / 移除」是整台一起处理。确认弹窗也变成一台只问一次（不再为同一台手机弹两三遍）。
  • v1.157设备名单上的名字说人话了（你问的「为什么有三个设备」）：同一台手机其实会占好几条 —— APP 里的页面（WebView）、APP 的后台轮询、传文件各是一个客户端，手机换网之后来源地址也会变，所以一台手机常常是 2~3 条。以前列表上只有一串 UA，看着像有三台陌生设备；现在每条都翻译成「语音助手 APP·页面 / ·后台 / ·接口」「安卓浏览器」「电脑浏览器」这种名字，下面才写原始 UA；名单顶上和弹窗里也直接写明白了「同一台手机可能占好几条，都点允许就行」。
  • v1.156多了两个能看能管的地方（你要的）：① 设备名单 —— 设置 → 智能 → 外网访问 → 「名单」，一台一台列出来：谁已允许、谁在等你确认（带 6 位号码）、来源地址、最后一次是几点；每一台都能当场「允许 / 拒绝 / 移除」。② 连接记录 —— 同一行的「连接记录」，按时间倒着列「谁、什么时候、干了什么」：连上来、发命令（还能看到发的是什么）、看屏幕、取文件、传文件、以及在门口发生的事（新设备想连、你允许/拒绝了、有人令牌连错被关门）。记录存在程序目录下的 `phone-access.jsonl`，最多留最近 800 条，能「打开文件」看原始内容、也能一键清空。
  • v1.155给公网那道门又上了几道锁（你要的：防止别人来操控电脑）。手机入口现在是公网地址，所以加了四样：① 新设备要你点头 —— 每台设备第一次连进来，手机上只会显示一个 6 位配对码和「等你在电脑上点允许」，电脑这边同时弹窗「有台新设备想连进来（号码 / 来源 / 设备）」，你点了「是」它才进得来；令牌就算泄漏了（截图、转发、浏览器记录），别人拿到的也只是那一页。② 手机令牌一键更换：设置 → 智能 → 外网访问 → 「手机令牌 → 换一条」，旧的立刻作废（不用重启程序就生效），换完手机重新扫一次码就成。③ 设备名单：那一行能看到配对了多少台、有几台在等你确认，也能「全部清除」（清完谁都得重新确认一遍）。④ 令牌也变「活的」了：以前换令牌要重启才生效，现在存盘即生效。
  • v1.154公网地址（Tailscale Funnel）：手机终于可以「什么都不装」了。以前人不在家，手机上得再装一个 Tailscale、后台常驻一个 VPN；现在 设置 → 智能 → 外网访问 多了一行「公网地址」，点「开（手机免装）」就把手机入口挂到 https://<你的固定域名>/ 上（对外走 443，内部照旧转发到 8765），手机浏览器或 APP 直接打开这条就行 —— 不装 VPN、后台不留东西。顺手把这道公网门看紧了：手机令牌从 12 位换成 40 位长令牌（早期安装包里漏出去过短的，一律作废，手机要重新扫一次码），并且同一个来源令牌连错 8 次就关门外半小时（以前令牌错了只回一个 401，不痛不痒）。代价说在前面：这条地址是公网可访问的（全靠长令牌守门），域名会进证书透明度日志、会有扫描机器人来敲门；Funnel 也有带宽限制，打字够用，传大图大视频会慢。想回到「只有自己的设备能连」，点那一行的「关掉」。
  • v1.153修了两个「别人那边会出问题」的（顺手查出来的）：① 网站上的 update.zip 根本没生成 —— 更新清单里写着 `update_url: update.zip`，可生成网站的时候只放了 app.apk / pc.zip，所以别人点「检查更新 → 一键更新」下载到的是一个 404；现在更新包跟着一起放上去了。② 老 Release 里还挂着带你令牌的旧安装包 —— 早期那几版手机 APP 的「出厂地址」写死过开发机的地址 + 令牌，而那些 app.apk 一直躺在 GitHub 的 Releases 里（仓库里攒了 12 个 Release），等于把旧口令一直挂在公网上；现在发布流程加了一步：每发一版就把老 Release 全删掉、只留最新那一个

手机端最近的更新（v1.27）

  • v1.27「正在连电脑」再也不会一直转下去了（你反馈的：卡了两分钟）：上一版是「先探路、探完再加载」，白白多等 3 秒；更要命的是——要是猜的那条地址根本不通，安卓的 TCP 超时能拖到两分钟，那一页就一直转。现在改成：① 打开立刻用「上次真的打开成功的那条地址」开始加载，不空等；② 后台同时探几条路（局域网 / 上次用的 / 记住的公网地址），只有「刚才猜的那条其实不通」才切过去，顺便把最快的那条记下来，下次直接走它；③ 12 秒还没进页面就自动换成「连不上」那一页（上面有重试 / 扫码连接 / 改地址），那一页上也多了个「一直连不上？点这里」的按钮 —— 再不会让你对着一圈转的动画干等。服务端还顺手开了 gzip：那一页 76KB 压到 22KB，手机少下一大半
  • v1.26打开不再黑屏了（你反馈的）：以前 APP 一开只有一块深色空屏 —— 因为那一下什么都没画，而且它会直接去加载「上次那条地址」，那条路要是不通（比如人在外面、地址却是家里局域网那条），就得等系统自己超时，几十秒才轮换。现在两步一起改：① 打开立刻画一页本地的「正在连电脑…」（带转圈，不联网所以是瞬间的）；② 同时在后台并行探几条路 （局域网那条 / 上次用的 / 记住的公网地址），给每条 1.8 秒，谁先通用谁 —— 在家自动走局域网、在外面自动走公网地址，再也不用先白等一次超时。顺便：「重试」也重新挑路，不在一棵树上吊着；网页资源的缓存也放开了（以前每次打开连图标都重下一遍）
  • v1.25手机上不用再管 Tailscale 了（你问的）：安卓规定 VPN 必须是独立应用，所以 Tailscale 那个 APK 还得装一个（这一条改不了）—— 但现在你只需要开语音助手这一个 APP：① 「外网访问」里多了个 「🔁 后台自动连（设一次）」，点一下带你到安卓的 VPN 设置，把 Tailscale 设成「始终开启的 VPN」，以后它自己连着、界面再也不用打开；② 地址切换也自动化了 —— 打开时局域网（在家）要是连不上，APP 会自己改走记住的那条外网地址；③ 连不上那页现在说准原因：没装 Tailscale / 装了但没连上 / 已经连着那就是电脑那边的事，而不是笼统地怀疑「你是不是开着 VPN」
  • v1.24出厂地址不再带开发机的地址和令牌：以前 APP 默认填的是开发机的局域网 IP + 它自己的口令 —— 等于把口令跟着 APK 发给每个人，同一张网里的人拿到它就能指挥那台电脑。现在默认是一个明显占位的地址，第一次打开会看到一页中文说明：点「扫码连接」照电脑上的二维码，或者点「改电脑地址」手填，就接上了。已经用过的人不受影响（存过的地址还在），只有点「恢复出厂地址」才会变成这个占位值
