📶 想在外面（不在同一个 Wi-Fi）也能用？不用另外找软件 —— 电脑端 设置 → 智能 → 外网访问 点一下「一键开启」（它会自己把 Tailscale 装好、把登录页开出来给你登）；手机 APP 里 设置 → 外网访问 点「装 / 开 Tailscale」， 它会自己把 APK 下下来装上，回来点「用这条地址连」就切过去了。只在家里用就不用管这一栏。
（不想让 APP 自动装的话，也可以直接下 官方的 Tailscale apk）

怎么用（三步）

  1. 电脑端：下载 → 解压 → 双击 1-安装语音助手.cmd，装好桌面上会有图标
  2. 手机端：下载 APK 装上，打开 APP 后点左上角「扫码」
  3. 电脑上点悬浮窗的「二维码」按钮，用手机照一下就连上了 （手机和电脑要连同一个 Wi-Fi）

电脑端最近的更新（v1.224）

  • v1.224多语言模型与多 Agent 基础：新增 STT/TTS provider 注册、可提供参考音频的声学回声消除，以及最多 10 路的有界 Codex worktree worker 管理器。
  • v1.223P3 本机安全：任务数据改为 Windows DPAPI 加密落盘；Android 地址、令牌和设备号迁移到 Android Keystore AES/GCM，旧明文设置自动升级。
  • v1.222结构化语音动作：新增发送、切换会话、批准、拒绝、取消任务、查询任务状态和新建任务的动作协议；显式命令不再只靠自由文本投递。
  • v1.221品牌归一：鳍舱、FinDeck、大肥鱼三层命名统一到桌面入口、手机页、PWA、Android 应用、安装更新和教程；旧脚本名、安装包名、数据目录与兼容路径保持不变。
  • v1.220连续语音基础：新增双工轮次状态、持续语音插话检测、播报中自动停 TTS、自听回声转写过滤和可插拔 STT/TTS 接口；真机麦克风回声与误唤醒仍需设备验收。
  • v1.219手机新增任务台：任务状态、待批准队列、风险与命令、工具调用、测试结果和文件变化可从手机查看；批准、拒绝、取消、新建和运行中消息进入持久化任务存储，所有接口继续走原有令牌鉴权。

手机端最近的更新（v1.35）

  • v1.35鳍舱品牌与安全升级：应用标题和 Android 名称改为「鳍舱」，连接地址、令牌和设备号使用 Android Keystore AES/GCM 加密，旧明文设置自动迁移。
  • v1.34新增任务台：＋ 菜单里可以查看任务运行状态、待批准命令和风险、测试结果、文件变化摘要；支持新建任务、批准、拒绝、取消，运行中消息会进入队列。
  • v1.33桌宠开关搬进设置并显示真实状态：网页设置里新增开/关，APP 原生桥补了 `petOn / setPet`，开关会直接控制悬浮桌宠服务，不再需要左侧抽屉单独放一个桌宠按钮。
  • v1.32手机悬浮桌宠加了「饭碗」和尺寸分开调：手柄上「饭碗」显示电脑的余额 / 今日 / 近 7 天 / 最近一步；「宠」调鱼大小（含超小号），「区」调活动透明区域；鱼身仍然点击穿透，不挡微信。
