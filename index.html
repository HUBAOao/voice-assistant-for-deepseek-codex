怎么用（三步）

  1. 电脑端：下载 → 解压 → 双击 1-安装语音助手.cmd，装好桌面上会有图标
  2. 手机端：下载 APK 装上，打开 APP 后点左上角「扫码」
  3. 电脑上点悬浮窗的「二维码」按钮，用手机照一下就连上了 （手机和电脑要连同一个 Wi-Fi）

电脑端最近的更新（v1.175）

  • v1.175手机入口的「＋」里多了「桌宠」：打开就是大肥鱼 Live2D，能自己走、能拖能摸；电脑在朗读时它会停住做说话动作。形象资源随安装包带（只带 web，不带 377MB 的 Electron 本体），手机连上电脑就能用。
  • v1.174修了朗读被「¥ / ≈」这类符号打断的问题：送进克隆声线前会转成「元 / 大约」，不会再因为一个符号整段退回旧音色或没声音。
  • v1.173声音输出可选设备：设置 → 声音 → 输出设备，能切系统默认 / 耳机 / 显示器扬声器；耳机没戴或没连时不会再「听不见」。桌宠在朗读时会停住并做说话动作。
  • v1.172悬浮窗展开收起换了实现：主浮窗不再改尺寸，设置面板改成独立窗口淡入淡出，不再每帧重排/重画；顺手修了「两个悬浮窗」和桌宠拖不动（拖出角色后卡在 drag）。
  • v1.171设置里多了「集中记忆」：说「集中记忆归档」或点「归档」，才会把全部 Codex 对话 + 事实记忆 / 便签 / 记账 / 日程 / 日记收成一份「集中记忆归档.md」；说「查看记忆归档」或点「查看」只打开上一次的，不会自动重建、不会定时跑。
  • v1.170克隆声线咬字修了一处：像「记事本」这种总被念成「计时本」的词，送去合成时会换成发音稳定的同义说法（「文本编辑器」），屏幕上的原文和字幕不动；语速也从偏快的 +8% 调到 -5%，听着更稳。

手机端最近的更新（v1.30）

  • v1.30大肥鱼桌宠能做到手机上、而且浮在所有 APP 上面了：手机入口顶部常驻「桌宠」按钮，点一下变成一个悬浮在所有应用之上的小窗——桌面、微信、浏览器里都在。顶部小条拖动位置，下面的鱼能摸、能自己动；电脑在朗读时它也会做说话动作。第一次点会先让你允许「显示在其他应用上层」。
  • v1.29手机页不再吃缓存了（你反馈的「你改的东西我手机上看不到」）：以前为了省流量，网页壳允许缓存，结果我这边改完手机还在用旧的页面 —— 面板、忙完了提示、气泡那几处你当然看不到。现在改成每次打开都重新取页面（图标这类也一起重取，慢一点点，但保证你看到的永远是最新的）。装完这一版，前面那几次改动才会真的出现在手机上。
  • v1.28手机在电脑名单里现在真的只有一条了（你问的「为什么有三个设备」）：以前 APP 里的几个客户端各算一台 —— 页面（WebView）、后台轮询、发语音用的是不同的 HTTP 客户端，谁也不认识谁。现在它们共用一个设备号：服务端第一次发一个 `va_dev`，APP 存下来，Java 这边的请求都带上它，网页那边的 cookie 也塞同一份。以后同一台手机不管开几个入口、在家还是在外面换网，电脑上都只算一条记录。
  • v1.27「正在连电脑」再也不会一直转下去了（你反馈的：卡了两分钟）：上一版是「先探路、探完再加载」，白白多等 3 秒；更要命的是——要是猜的那条地址根本不通，安卓的 TCP 超时能拖到两分钟，那一页就一直转。现在改成：① 打开立刻用「上次真的打开成功的那条地址」开始加载，不空等；② 后台同时探几条路（局域网 / 上次用的 / 记住的公网地址），只有「刚才猜的那条其实不通」才切过去，顺便把最快的那条记下来，下次直接走它；③ 12 秒还没进页面就自动换成「连不上」那一页（上面有重试 / 扫码连接 / 改地址），那一页上也多了个「一直连不上？点这里」的按钮 —— 再不会让你对着一圈转的动画干等。服务端还顺手开了 gzip：那一页 76KB 压到 22KB，手机少下一大半
