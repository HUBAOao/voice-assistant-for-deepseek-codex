想让「任何人在任何地方」都能下载，就得把这个网页放到公网上去。
这个文件夹里的东西是**完全独立**的（两个安装包就在里面，不依赖你的电脑开着），
挑下面任意一条路都行：

【最省事】用单文件那个：下载页-单文件.html
   两个安装包是直接嵌在文件里的，双击就能下，连文件夹都不用。
   微信/QQ 直接把这个文件发给别人也行（他存下来用浏览器打开就能下）。
   缺点：文件 4~5 MB，用微信发的时候记得选「以文件发送」。

【推荐，永久网址】静态网站托管（免费，不用买服务器）：
  · Cloudflare Pages：dash.cloudflare.com → Workers & Pages → Create → Pages
    → Upload assets → 把这个文件夹整个拖进去 → 得到一个 xxx.pages.dev 网址
  · Netlify：app.netlify.com/drop → 把文件夹拖进去，立刻给一个网址
  · GitHub Pages：把这个文件夹里的东西传到一个仓库 → Settings → Pages
    → Source 选 main 分支根目录 → 得到 https://用户名.github.io/仓库名/
  三个都是传完就有网址，别人打开那个网址就能下这两个应用（手机也能下）。

【国内】如果国内访问上面几个慢：传到阿里云 OSS / 腾讯云 COS 的静态网站，
   打开「静态网站托管」，把 index.html 设成默认首页即可（要实名，几块钱一个月）。

注意：网址是 https 的时候，手机下载 APK 更顺（安卓对 http 的安装包会多问一句）。

电脑上跑着助手时，别人打开 http://这台电脑的IP:8765/dl 就是这一页。
